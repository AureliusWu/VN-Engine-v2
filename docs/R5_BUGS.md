# R5 问题与回归

本轮范围为作者输入保护、异步打开、阅读与媒体生命周期，版本 0.8.1 alpha。基线与旧码失败观察见 [r5-preflight.json](r5-preflight.json)。

| 编号 | 修复 | 关键回归 |
| --- | --- | --- |
| R5-B001 | 独立字段提交队列，聚焦保存先提交；错误输入保留；未记录反馈及说明使用独立作者草稿 | 连续 Ctrl+S / 实际下载字节，刷新恢复，无效 JSON 后改节点 ID，取消 / 确认替换，反馈草稿隔离 |
| R5-B002 | 工程打开绑定操作序号与编辑版本；保存绑定实际快照；终审文档使用独立后选优先序号 | 慢样例 / 文件 / 受控原生桥、等待期间编辑、先选 A 后选 B、失败 / 取消保留原文档 |
| R5-B003 | 动作区重建时保留同一可用控件焦点，控件消失回到阅读宿主 | 鼠标到键盘 / 数字键、结局、小游戏开关与完成、外部输入不被抢焦 |
| R5-B004 | 跟踪当前 SE 的暂停意图与播放尝试，从原位置续播 | 实际 HTML 音频 currentTime / 同实例、面板 / 后台 / 隐藏、结束 / 关闭 / 换段 / 读档 / 销毁与迟到 Promise |
| R5-B005 | 开始核对即撤销旧通过状态；当前异常显示 BLOCKED 与原因；旧请求不回写 | 超时异常、重试、挂起期间旧 QA 不通过、新请求完成后旧失败、源变化与离开面板 |

最终实现和跨平台结果见 [R5 验证](VALIDATION-v0.8.1.md)。受控原生桥浏览器夹具不等同于系统对话框或实际 WebView2；原生 CI 单独记录。没有将这些回归扩大解释为无缺陷、作品终审或实体设备验收。
