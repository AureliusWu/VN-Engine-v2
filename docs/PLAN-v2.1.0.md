# v2.1.0 工程导入与 DSL 源稿

基线为正式版 v2.0.0（`67007fb5758473ac5775ef3ff8b5c5ce52a23b3d`）。Chromium 复现了普通 JSON 含空台词时，Studio 报错前已更换工程标题、草稿身份和资源绑定。同一版本保存并重开 `.vnproj` 后，编译后的台词仍在，DSL 输入框为空。

先修工程导入。Studio 在打开工程、应用 JSON 和恢复文件前检查台词成员、调查节点和证据目录形状，并提前运行诊断。结构正确但有断链、无效引用等问题的工程仍可进入面板修复。SDK 的只读诊断继续接受待检查的数据。

再把 DSL 源稿作为 `.vnproj` 的可选作者字段。保存时记录当前文本，未编译或暂时无效的文本也可保存。显式应用编译结果时，用一次命令写入源稿与运行剧本，撤销和重做同时还原两者。图形与 JSON 编辑保留源稿，下次编译与应用仍需作者确认。运行 JSON 不包含作者字段。

恢复文件保留已保存源稿和另行未保存的文本，并继续保留原始运行 JSON 的字节。旧 `.vnproj` 与旧恢复文件继续可读。新增源稿的恢复文件适合在 2.1 及以上版本之间交接。

按同一 `main` 提交检查本地浏览器、编辑器、Linux 和 Windows CI。下载 Windows 候选工件，核对外层 SHA-256、内层包和构建身份，再用下载包的 Studio 执行离线复测。
