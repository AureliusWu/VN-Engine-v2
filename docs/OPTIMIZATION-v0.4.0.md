## 编辑身份与兼容

变量改名只修改定义与确切的变量引用，保留台词与数值；Script 存档本来就从选择日志重建变量，因此将验证旧格式路线在纯改名后仍可恢复。更改类型 / 初值 / 边界可能改变故事，应重新执行用例；含引用的变量禁止改类型和直接删除。

章节改名同步准确的章节动作、台词定位、结局 ID、演出键与布局；不对正文做文本替换。章节排序改变开场与解锁顺序，旧路线结果失效并需重跑。含回看存档的工程在章节身份 / 排序变更前先要求移除并重新录制回看点，避免猜测不透明快照；删除章节前必须先清理外部引用。已发行作品的身份或故事顺序变更仍需单独安排 storyVersion 与存档迁移，不由本轮自动执行。

每阶段小步提交 main，不强推。检查共享构建目录，顺序执行本地构建与测试。版本升级保留 alpha 的真实能力边界，不把引擎样例视作正式作品或实体设备验收。
