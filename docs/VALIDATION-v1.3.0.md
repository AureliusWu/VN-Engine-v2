## 行为与专项证据

- DSL 支持 block / line 上显式、可前向引用的 cue；17 条演出指令与手写 IR 相同，两条路线、重放和存档恢复保持一致。新 P3 Node 21 项通过，与既有 P1 DSL 合并的最终回归 35 项通过。旧编译器无法接受新语法的原始失败保留于 `test-results/p3-dsl-old-code.log`。
- 纯 API、CLI、Agent 对同一缺失语音与错误种类给出一致的 code / path / span。清单检查不读取媒体文件；失败不产生可应用程序或 CLI 输出。上下文身份、预算、诊断上限、分页与资源变化后的游标失效均有覆盖。CLI 语法错误优先于读取外部上下文。
- 真实 Chromium 专项 4 项验证画面、BGM / 环境音 / 语音 / 音效、暂停嵌套、两条路线、恢复 / 回滚不重放历史一次性效果，以及真实音频图释放。使用隔离存储，已有 localStorage 哨兵保持原值。
- Studio 专项 3 项验证真实工程 / 目录输入、候选预览、一次可撤销应用、缺失及错误种类诊断定位，以及目录改变后重新检查已编译候选。1360 / 390px 截图与报告保留于 `test-results/p3-studio/`。初次夹具未绑定目录导致预览等待失败，原始 `p3-studio-unbound-directory.log` 保留；修正实际目录输入后重跑，不降低图像断言。
- 生成包专项 5 项验证子目录部署、两个结局、真实媒体清除、玩家与 Studio 断网后新页重开。玩家 manifest / 网络 / cache 均不含文本编译器、上下文检查模块、原始文本或 source map；Studio 保留并缓存作者模块。实际文件输入与浏览器音频图不代表人工系统对话框或实体听感验收。

专项报告分别为 `test-results/p3-runtime/REPORT.json`、`p3-studio/REPORT.json` 和 `p3-package/REPORT.json`。技术样例的美术仍为 DRAFT，不能将技术门禁通过标为内容终审完成。

完整浏览器 46 个脚本与完整编辑器 20 个脚本全部通过。命令与日志、专项摘要、LF 规范化后的源文件 SHA256 见 [机器记录](v1.3.0-validation.json)。独立只读复核未发现 CLI、Studio、Agent 边界的阻塞问题。

## 性能与体积

使用已验证与基线 `4c3500d` 一致的 81 个旧 TS 源文件 / 保留编译输出，和隔离的新版本快照比较。每个工作负载预热一次，随后固定三轮交替执行，导入、GC、断言和打包不计入编译计时；所有样本保留。

首次比较中旧 DSL 中位 74.39→95.33ms（+28.16%，FAIL），运行期间存在其他测试负载；原始失败未覆盖。无并发负载复核中位 73.09→60.12ms。随后实际移除了无 cue 脚本不需要的索引和 owner 分配，再为改变后的代码执行固定三轮最终验证：

| 工作负载 | 旧版本中位 / 最慢 | 最终版本中位 / 最慢 | 判定 |
| --- | --- | --- | --- |
| 7000 行旧 DSL，无 cue | 53.65 / 61.82ms | 52.90 / 68.18ms | 未见明显中位退化，样本含运行噪声 |
| 7000 行 + 7000 条 cue + 清单检查 | 不支持 | 196.79 / 208.03ms | WARN，大文本同步作者操作观察项 |

不据此宣称整个引擎或玩家启动提速。最终性能报告为 `test-results/p3-performance-optimized.json`；初始、空闲复核及原始样本均保留并列出哈希。未来大文本异步编译需要独立规划。

最终代码重新打包并按 lib JS 逐模块累计 raw / gzip：玩家仍为 68 模块、423,183 / 121,174 B；Studio 81→82 模块，raw 587,420→600,686 B（+2.26%），gzip 164,746→168,403 B（+2.22%）。这不是下载耗时测量；早期优化前的包体测量没有被重标为最终字节。完整读数为 `test-results/p3-payload-final.json`。
