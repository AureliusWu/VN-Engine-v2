# 1.0.0 引擎更新说明

本版本收敛 0.8.2 后已复现的状态、交互与资源恢复问题，并确定 [1.x 兼容约定](V1_COMPATIBILITY.md)。执行方案见 [V1_PLAN.md](V1_PLAN.md)，七类问题及证据见 [V1_BUGS.md](V1_BUGS.md) 和 [验证记录](VALIDATION-v1.0.0.md)。

## 行为变化

- 审阅文件读取挂起时，后选文件、后续编辑和新工程受到保护；迟到结果不会覆盖当前数据。保存应答只对应实际保存快照，等待期间的新反馈保持未保存状态。
- 原生资源绑定与当前工作区实例、编辑版本及请求顺序绑定，旧目录不会施加到后来打开的工程。
- 展开存档覆盖确认时默认聚焦取消，取消后回到原槽位。Enter / Escape 可连续使用；存储不可用时回到可操作的关闭控件，外部输入不被抢焦。
- 系统和播放器的减少动态偏好共同生效，场景 flash / fade / shake 会被禁止或取消；恢复正常偏好不会补播已消费效果。
- 临时图片失败在下一次真实访问重试，打字刷新不重复请求；成功缓存和旧访问 / 销毁清理保持有效。
- manual / quick / auto 读取拒绝与 key 不符的 envelope.slot，并保留损坏原文；合法旧格式与明确配置的逐级迁移仍可读取。

## 升级与兼容

1. 保留现有工程、作者审阅和玩家备份，使用同一 game、故事 version 及存储 namespace。
2. 源码环境执行 `npm ci`、`npm run build`，或从本次通过的 Windows 工作流下载 1.0.0 便携包。
3. 直接打开已有 schema 1 工程；浏览器会话资源目录仍按原规则重新绑定。升级引擎不自动重排内容 ID 或迁移四作。
4. 既有 public exports 与数据协议见兼容约定。新增 `npm run test:v1` 可执行本版本专项；完整检查仍使用 `npm run check`、`npm run test:browser` 和 `npm run test:editor`。

本版本包含一份由实际 0.8.2 dist 生成的合成工程 / 存档夹具，1.0.0 会验证打开、实际路线后读档恢复、作品身份、扩展字段及原始存档字节；它不是正式游戏的迁移或发行证据。

旧独立包继续携带旧运行时；升级仓库后需从源工程重建，再以当前源 / 引擎 / 提交身份执行 QA，不能只改旧 manifest 的版本号。

本次交付代码和 CI 构建，不创建公共 npm、GitHub Release / tag 或签名安装器。1.0.0 是引擎版本，不代表所有作品内容、素材或实体设备已经验收。
