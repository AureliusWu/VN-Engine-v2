## 协议与实现边界

- 引擎版本 0.5.0、协议 vn-agent-v1、项目 / 编辑器 / 存档 schema 1 分别维护。能力清单仅列已实现操作。
- 纯数据 SDK 不直接接触 DOM、磁盘、玩家存储或音频。Node 文件适配器注入资源读取、预览和构建能力；CLI 与 Node SDK 使用相同入口。
- 批次在隔离文档上执行，可暂时断链；结束时复用真实作者诊断和运行校验。失败没有候选写入。稳定 ID 为主要定位方式，未修改扩展字段保留。
- 写入使用协作文件锁和提交前源 SHA256 复核。同批回执记录请求摘要与前后哈希；崩溃后只根据实际文件字节确认已应用 / 未应用 / 冲突，不猜测或重复追加。不合作的外部写入仍可能与提交竞争，必须如实报告边界。
- 预览通过合法路线在真实会话和渲染器中执行，隔离 Save / Meta / 已读；正式打包复用现有门禁，技术通过不提升人工验收状态。
- 输出、操作、输入大小、路线和预览设置显式预算；超时或未验证保留定位与实际状态。

## 验收清单

1. 纯 SDK 与 CLI 的命令、响应、schema 和文档一致；每个错误有稳定码与定位。
2. VN / 聊天 / Script / 调查创建与实际路线，Rain 读取 / 验证 / 执行保持兼容。
3. 批次失败、过期哈希、重复 ID、非法请求、缺图、断链、预算、子进程崩溃及恢复有实际证据。
4. 全程通过接口完成两个新独立项目：创建、编辑、资产 / 演出、用例、校验、测试、预览与打包。
5. 核心 / Python / 来源 / 完整浏览器 / 编辑器、Windows CLI、Windows 原生重启和四样例 QA 按确切提交记录。
6. npm / 锁文件 / 引擎 / 原生程序 / 产物 manifest 一致为 0.5.0。
