# v1.4.0 Studio 后台编译与取消保护

日期：2026-10-30。基线 `2135b8b27850811e388384b841308ff5b2d7e305`（v1.3.0），本地与远端 main 一致、工作区干净。参考依据见 [研究对照](REFERENCE-MINING-v1.4.0.md)。本轮直接实施，不创建正式 Release / tag，不迁移四作。

## 选择依据

Studio 点击编译仍同步执行；draw / changed 还会重新克隆、检查整个编译结果，并先完整格式化 JSON 再截断。上一轮 7000 行 / 7000 cue 同步作者操作最慢 208.03ms，仅是 Node 观察项，不能当作本轮浏览器响应测量。Yarn 的任务取消、Inky 的独立编译会话及旧结果拒收提供参考，本仓库路线检查也已有 Worker 生命周期。先解决已有大文本入口，再独立设计多文件身份与聚合预算。

## 实施范围

1. 作者专用 module Worker 执行现有 compileTextScript、checkTextScriptProject 和有界 JSON 预览格式化；同步公共 API / CLI / Agent 不变，不加入运行依赖。
2. 任务监督器处理 requestId、真实 terminate、10 秒期限、error / messageerror / 初始化与发送失败、清理和重试。模块导入无 Worker / DOM / 存储副作用，无同步主线程降级。
3. Studio 显示运行状态与取消入口。任务绑定当前文本、工程身份和最小 id/kind 清单。新文本、新编译、工程替换、reset / dispose 和清单变化使旧结果失效；已尝试文本在清单变化后后台复核，不自动启动候选预览。无关标题等变化复用结果。
4. 预览和应用前再核对当前文本 / 清单；运行期间禁止应用。应用仍只替换 program，为一次撤销事务；失败、取消或过期结果不改 JSON。真实试玩及显式应用成本单独记录。
5. Studio 离线包包含任务与 Worker 及其依赖，玩家包继续不带作者模块、DSL 或 source map。子目录部署和断网新页重开均执行真实编译 / 应用 / 导出。

## 验收与证据

- 固定三轮基线和新实现测量，区分主线程心跳 / long task、后台总耗时、结果展示及真实试玩成本，保留全部样本和失败。
- Node 替身测试取消、乱序、超时、构造 / 发送 / 消息错误、重试及销毁；真实浏览器另验证 Worker 与生命周期，模拟延迟 / 失败明确标明范围。
- 既有 P1 / P3 文本、诊断、撤销、源范围、真实媒体与离线包继续通过；旧同步测试只调整等待条件，不降低内容断言。
- 提交前执行 npm run check、完整浏览器 / 编辑器；本机既有四项 symlink EPERM 原样保留，由同提交 Linux 全量核心补足。Windows 执行同一 P4 专项及原生 WebView2 / 文件 IO / 完整重启，人工系统对话框与 CI 预设路径分开报告。
- 刷新 provenance、版本与真实记录；推送 main，核对精确 SHA 两条 CI 和提交锁样例 QA。结果见 [验证记录](VALIDATION-v1.4.0.md)。

多文件 / include、翻译目录、条件 / once 选项和跨版本存档策略需独立契约，本轮不改变 DSL、IR 或存档格式。
