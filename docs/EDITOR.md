# VN Engine Studio 0.3

可视化编辑器的可用初版。与播放器共用 `EngineProject`、真实状态机、资源清单、调度与渲染，没有另一份预览用剧情逻辑。

```bash
npm ci
npm run demo
# 打开 http://127.0.0.1:4173/editor/
```

## 作者工作流

1. 新建视觉小说、聊天叙事、条件剧本或调查工程，也可打开引擎独立样例或自己的 JSON / `.vnproj`。
2. 在节点图选择场景，编辑台词、出口、分支目标和资源绑定。拖动节点调整布局；键盘选中节点后 Alt + 方向键也可移动。撤销/重做保存最多 80 次命令；输入框内保留原生文本撤销。
3. 在资源清单登记 ID、类型、相对路径和许可，绑定包含这些路径的资源根目录。浏览器预览使用所选文件的临时 blob URL；工程里的相对路径不会被替换。Windows 通过原生文件桥读取清单文件。
4. 在实际引擎里从头试玩。编辑后自动重新启动预览，预览存档只保存在内存中，不写入正式游戏存档。错误状态保留上次有效预览，并禁用运行数据导出。
5. 在“路线测试”从头手动录制，完成录制添加实际步骤与期望；可编辑用例、撤销、独立 Worker 执行 / 取消和导出绑定工程的报告。工程修改会使录制和旧结果失效，失败可定位节点；完整规则见 [路线 QA](ROUTE_QA.md)。
6. 保存 `.vnproj` 保留工程、路线用例和节点布局；导出 `.json` 得到原生 `EngineProject`，不含编辑器字段，可直接使用 `npm run build:game -- project.json build/my-game`。

浏览器的保存使用下载；本地草稿独立保留。Windows 使用原生保存对话框及原子 JSON 替换，另存时复制已绑定的引用资源，并拒绝覆盖目标目录中内容不同的资源。手动选对话框是用户行为，CI 使用预设路径检查相同的文件读写处理链。

## 玩法和数据

| 类型 | 属性面板 | 高级 JSON |
| --- | --- | --- |
| VN / 聊天 | 节点、台词、聊天/通话呈现、选择、数值变化、连接、场景/台词演出绑定 | 章节续接、条件变体与完整工程字段 |
| 条件剧本 | 台词、选择、直接连接、条件出口、结局、演出与媒体 | 变量声明、效果数组和带末项兜底的条件路由 |
| 调查 | 节点类型、正文、调查动作、收集和所需证据、同章连接、节点结果 | 证据目录、隐藏/重置规则、章节、热点、谜题和完整约束 |
| Rain 兼容 JSON | 原格式打开、诊断、实际自研 VM 试玩和原格式导出 | 使用工程 JSON 编辑；本版不把兼容数据转换成另一种格式 |

条件路由、证据目录与章节目前通过 JSON 字段编辑，复杂动画时间线、多人协作和自定义插件界面仍待后续实现。兼容适配器的动态结局不由静态连线推断，编辑器明确提醒通过实际试玩核对。调查合法循环由库存联合状态检查，不套用 DAG 判定。

## 数据保护与限制

- 导入先解析，失败保留当前工程。命令原子提交，异常不污染历史；删除节点保留入站分支，暴露断链供修复。
- 重命名节点同步入口、入站引用、场景演出键和布局。已有发行作品重排台词或改 ID 仍需单独设计存档兼容方案。
- 草稿保存应用后的工程及 JSON 面板尚未应用的文本；恢复后本地资源目录需要重新授权绑定。草稿存储失败会明确提示保存文件。
- 显式资源绑定检查 ID、类型、路径、字体许可；绑定目录后再检查实际文件是否齐全。绘制资源失败仍由播放器处理，不冒充完整美术验收。
- 作者文本按文字显示，JSON 不执行 JavaScript。预览消息核对来源窗口和同源地址；Windows 文件桥仅允许可信编辑器顶层文档访问。
- 此工具仅编辑当前工程；四个正式游戏的迁移保持用户主动发起的独立步骤。

```bash
npm run build:studio -- build/studio
npm run test:editor
```

独立 Studio 包含编辑器、自研运行模块、本地样例、字体和许可。Windows 宿主直接使用同一份内容，见 [WINDOWS.md](WINDOWS.md)。
