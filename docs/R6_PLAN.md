# R6 实机复测与边界保护

日期：2026-10-30。基线：`b297a570e0156183b334552cd469ba8621abc78d`，目标版本：0.8.2 alpha。

本轮继续实际控制本机 Edge 的 Studio / 自研播放器；用确定性回归区分界面观察、运行语义和跨平台文件问题。只优化引擎，四作的正式数据、依赖与存档不迁移。

## 实施与交付

1. 保留旧代码失败证据，先新增能够失败的回归，再实现修复；共享文件策略与界面逻辑保持清晰边界。
2. 顺序构建和执行 `npm run check`、完整 `npm run test:browser`、`npm run test:editor`，避免同时写 dist；本机符号链接权限限制如实记录。
3. 修后重新实机复测 JSON 与隐藏 / 恢复键盘操作；实际 HTML 音频、子目录与离线生成产物、Windows 原生执行分别提供证据。
4. 更新版本、来源哈希、CHANGELOG 与验证记录，进行跨模块独立审查；合成音频检查不冒充主观听感或正式内容验收。
5. PR 的 Engine / Windows 检查通过后合并，再验证实际 main CI；本地与远端同步，删除本轮临时分支，仅保留 main。不强推。

实际执行进展以 [R6 问题表](R6_BUGS.md) 和本轮验证记录为准，未执行的检查不标记通过。
