# v2.1.1 验证范围

正式基线 v2.1.0 的浏览器复现覆盖三条路径。打开 CRLF 源稿后，Studio 编译后的多行台词含 LF，另存的源稿保留 CRLF。载入语法示例会直接替换当前输入和已自动保存的草稿。带待修 Rain 剧本和制作反馈的本地草稿切换了标题、草稿身份和素材目录后才报错。

回归使用真实 Chromium 与后台编译 Worker。DSL 检查原始源稿和共享编译器输出一致、点击范围准确定位、多行文本随工程保存，以及取消载入示例保留文本和编译结果。草稿检查通过 Studio 实际编辑、导出和恢复，分别覆盖本地草稿与便携文件。仍可核对的项目目标直接恢复，暂无法核对的台词目标和反馈意见继续随草稿保存。修复剧本后可恢复原目标，也可以明确选择其他目标。

本地、Linux CI、Windows 原生宿主、候选归档和解压后的 Studio 各留独立记录。归档校验核对 GitHub 外层摘要、内层 ZIP、Studio 清单与构建提交。Windows 自动化使用预设文件路径。独立样例用于技术验证。 [排查来源与实施计划](PLAN-v2.1.1.md)
