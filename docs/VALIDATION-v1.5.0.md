# v1.5.0 工程恢复与发行验证

日期 2026-11-06。基线 `f5aadb149f8beb516a3205fb0778a47f0add5bf2`。正式发行门禁、社区资料与范围见 [计划](PLAN-v1.5.0.md)。

## 作者数据

v1.4.6 的 Chromium 复现中，662 字节原始运行 JSON 恢复为 1313 字节的规范 JSON。工程对象相等，SHA-256 发生变化，原先匹配的运行证据被判为过期。v1.5.0 用真实 Chromium 测试原始 JSON、节点布局、未应用文本与 DSL 的恢复。新浏览器上下文导入后，运行导出的实际字节等于输入，重新导入原证据时来源仍匹配。坏文件、旧普通工程当恢复文件及伪造资源基址均被拒绝。旧本地槽继续可读。

原始 JSON 与编辑器文档只保留一种，SHA 从实际使用的来源计算。恢复文件导入后素材目录重新授权，来源匹配与素材字节、制作状态及内容验收分别判定。生成的离线 Studio 也实际执行了恢复文件导出与重新打开。

## 性能对照

Windows x64、Chromium 153、Node 24.14.0。v1.4.6 和 v1.5.0 的已打包 Studio 在同一 localhost 环境交替测试。每版三轮，每轮使用新上下文测冷启动，再用已安装 Service Worker 的新页测暖启动，实际选择工程文件并等待试玩显示目标台词。表中为中位 / 最慢。

| 指标 | v1.4.6 | v1.5.0 | 中位变化 |
| --- | ---: | ---: | ---: |
| 冷启动，ms | 263.29 / 343.31 | 282.52 / 287.34 | +7.30% |
| 暖启动，ms | 217.02 / 224.28 | 221.07 / 223.05 | +1.87% |
| 打开工程到可见试玩，ms | 358.33 / 362.25 | 345.69 / 350.18 | −3.53% |
| 包内 JS/CSS，字节 | 793378 | 804721 | +1.43% |
| 逐文件 gzip 后 JS/CSS，字节 | 236092 | 239431 | +1.41% |

这些本机样本均通过性能门槛。全部读数、夹具与包清单摘要见 `test-results/v150-studio-performance.json`。

## 平台与发行

本地通过 EditorModel 25 项、完整浏览器 48 个脚本和完整编辑器 21 个脚本。Windows 本地核心 387/391，四项符号链接夹具创建返回 `EPERM`，零跳过。工作流 Python 7/8，另一项夹具创建返回 `WinError 1314`。兼容 Python 6 项、schema、201 份来源、五样例结构与引擎清单通过。Linux 工作流执行这些夹具的原断言。

本地记录与源码指纹见 [机器记录](v1.5.0-validation.json)。同一提交的 Linux、Windows 原生和五样例技术 QA 分别保存。样例内容门禁保持 `BLOCKED`。正式 Release 的附件摘要、公开回读和下载包复测见 `test-results/v1.5.0-delivery.json`。
