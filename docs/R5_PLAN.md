# R5 实机测试与稳定性优化

日期：2026-10-29。基线：`622615a39ea05d446502d733c27055d5415f4411`，目标版本：0.8.1 alpha。

本轮由本机 Edge 的真实 Studio / 播放器操作发现问题，再用确定性回归核对原因。继续只优化自研引擎；四个正式游戏的依赖、数据与存档不迁移。

## 修复范围

| 编号 | 触发与问题 | 完成条件 |
| --- | --- | --- |
| R5-B001 | 表单保持焦点时 Ctrl+S 使用旧模型；未记录反馈失焦后丢草稿 | 保存包含当前输入；未提交输入和独立作者反馈草稿参与脏状态 / 恢复；校验失败保留编辑 |
| R5-B002 | 样例 / 文件 / 原生打开异步完成时可能覆盖后来的工程或编辑 | 后发操作优先，等待期间的编辑受到保护；迟到保存不能误标已保存 |
| R5-B003 | 鼠标点击后动作区重建删除焦点，数字键 / 阅读快捷键失效 | 新动作区保持合适焦点，结局 / 小游戏可恢复且不抢外部焦点 |
| R5-B004 | 打开设置等暂停未结束的 SE，关闭后不续播 | 同一音效从暂停位置继续；已结束、换段、销毁和过期异步播放不能复活 |
| R5-B005 | 终审核对读取超时或预算异常时面板一直显示正在核对 | 显示 BLOCKED 与原因；旧 PASS 失效；修复输入可重试，离开面板后旧请求不得回写 |

## 验证与交付

1. 保存旧码失败证据，实施独立回归；新增逻辑按模块分离，保持现有工程 / 存档协议兼容。
2. 顺序执行 `npm run check`、完整 `npm run test:browser`、`npm run test:editor`；使用本机已有 Edge 执行浏览器检查。
3. 重载本机界面复测鼠标 / 键盘、保存、审核错误与恢复，并记录实际可见结果；原生 Windows 验证与浏览器分别记录。
4. 更新来源 SHA256、CHANGELOG、版本与 R5 验证记录；不把合成审核或解码通过称为艺术 / 听感终审。
5. 临时分支创建 PR，等待 Engine / Windows 工作流通过，独立审查后合并；核对最终 main CI，再删除本轮临时分支。保留远端前移，不强推。

各项实际执行结果见 `VALIDATION-v0.8.1.md`，尚未执行的检查不得提前记为成功。
