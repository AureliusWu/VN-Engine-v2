# 后续工作

当前版本：**1.0.0**。本次将 R7—R10 的未实施预检收敛为作者状态、阅读交互、渲染恢复及兼容交付四阶段，见 [v1 方案](V1_PLAN.md)、[1.x 兼容约定](V1_COMPATIBILITY.md) 和 [v1 验证](VALIDATION-v1.0.0.md)。R1—R6 历史跨平台证据保持独立；指定作品的完整审核与引擎交付分开记录。

大工程全面性能改造、跨故事版本存档策略与联网协作留作后续独立规划，不在本轮自动开展。所有引擎优化都不授权迁移四作或 RESET。

## v1.0.0：兼容边界与工程交付

作者状态、存档面板、渲染恢复及槽位身份四阶段共同验收，既有公开入口和合法格式保持兼容。执行和失败记录见 [方案](V1_PLAN.md) 与 [验证](VALIDATION-v1.0.0.md)，具体平台与发行边界见 [兼容约定](V1_COMPATIBILITY.md)。

## R6：实机复测与边界保护（0.8.2）

本轮处理未应用 JSON、隐藏 / 恢复焦点、暂停期间首句音效、构建输出冲突和 Windows 大小写路径碰撞。范围与完成条件见 [R6 计划](R6_PLAN.md)，实际验证另行记录，不自动迁移正式作品。

## R5：实机测试与稳定性（0.8.1）

按实际 Studio / 播放器操作发现的问题，完成聚焦输入与反馈草稿保护、异步打开 / 保存隔离、阅读焦点、动作音效续播和终审异常恢复。完整本地浏览器 / 编辑器与实际 Windows 原生证据分别记录于 [R5 验证](VALIDATION-v0.8.1.md)；后续范围需另行发起，不自动迁移正式作品。

## R4：修复与 AI 模拟审阅（工程交付完成）

0.8.0 增加独立 acceptance 文件、实际输入 / 源绑定、SDK / CLI / Studio / Windows 共用策略。已关闭过期 QA、Neutral 继承、成品清单 / 启动 / 缓存漏项和目录别名五类缺陷。最终实现 b10feae 的核心、完整浏览器 / Studio、真实 Windows 文件与进程重启及新包离线复验通过。

实际样例的正文 / 单项原图已审阅；全量视觉整合、主观听感和实体设备仍 UNVERIFIED，素材保持 DRAFT。AI 模拟审阅可以满足当前内容门禁，不要求真人内容签字；缺少实际输入或覆盖时不能补写 PASS。测试包与 Release 状态见 [0.8.0 版本说明](RELEASE-v0.8.0.md)。

## 0.1：四作能力沉淀

已完成独立剧情/调查核心、四作兼容入口、媒体生命周期、历史/存档边界、来源记录与原码对照。

## 0.2：自研运行闭环

已实现自己的数据解释器、播放调度、DOM 图层/聊天/调查渲染、输入/弹层/设置/存档、声音宿主，以及独立作品的离线构建。Rain 数据可直接由自研 VM 执行，四种样例可在子目录与断网状态运行。

## 0.3：作者工具与 Windows 宿主

已加入可视化节点图、分支和台词属性、资源绑定、诊断、撤销、草稿恢复与同一执行链预览。Windows 宿主提供原生窗口、受限文件 I/O、本地作品与持久化，并通过独立工作流验收。详见 EDITOR、WINDOWS 和 VALIDATION 文档。

## 0.4—0.6：作者工作台与 AI 生产

0.4 已补齐变量 / 章节工作台与有序效果；0.5 提供统一 SDK / CLI、回执恢复、真实预览和构建；0.6 提供制作上下文、实际素材探测 / 导入、主题及内容审查。条件 / 证据表单、正式图层与时间线、收藏作者工具等能力的具体范围见对应版本验证记录。

## 后续作者需求

R3 计划、实现范围与验收矩阵见 [记录](R3_PLAN.md)。更深入的演员定位、演出扩展、资产包协作和大工程性能需以具体作品需求与测量结果另行确定，不据旧路线图重复实现已经验收的基础能力。

## 引擎宿主与稳定性

优先优化执行、调度、资源生命周期、演出与性能；桌面宿主也先以引擎独立样例验证。四个正式项目维持各自运行链。

## 四作迁移：仅用户主动提出后执行

迁移属于最后阶段。用户主动、明确提出后再制定和执行迁移方案，保留人物、玩法、数据和存档身份，并分别验证实际平台。本文不授权提前接入任何原项目。原 Rain 二进制存档不会被自研 VM 直接读取，需要专门的迁移桥。

## 发行标准

继续完善跨版本存档策略、资源诊断、可复现构建和平台验收，再决定包发布。每阶段按实际证据记录，不把原生平台未执行或正式素材未审读记作完成。
