# 后续工作

当前版本：**0.7.0 alpha**。R1 / R2 / R3 已有实现，各提交的实际状态分别见 [0.5.0](VALIDATION-v0.5.0.md)、[0.6.0](VALIDATION-v0.6.0.md)、[0.7.0](VALIDATION-v0.7.0.md)。R3 从完整目录 / 修改影响走到 Studio / 独立审阅，再到 SDK / CLI 两轮修订、重构建与跨平台复核。收尾后停止，不自动开始下一轮。

大工程全面性能改造、跨故事版本存档策略与联网协作留作后续独立规划，不在本轮自动开展。所有引擎优化都不授权迁移四作或 RESET。

## R4：修复与 AI 模拟审阅（实施中）

用户于 2026-10-28 要求 R4 以修复和 BUG 查漏补缺为主，并将文案、美术和听感终审改为 AI 模拟人类审核。计划目标为 0.8.0 alpha，当前运行版本仍为 0.7.0。优先修复已复现的旧 QA 未随正文失效、Neutral 关联检查遗漏和成品清单漏项误报 PASS；统一新的审核来源 / 输入绑定、Studio / SDK / CLI / 正式门禁与真实技术回归。详情见 [R4 计划](R4_PLAN.md) 与 [预检证据](r4-preflight.json)。用户已授权执行；实现进度见 [0.8.0 验证](VALIDATION-v0.8.0.md)，保留 R1—R3 的历史结果。

## 0.1：四作能力沉淀

已完成独立剧情/调查核心、四作兼容入口、媒体生命周期、历史/存档边界、来源记录与原码对照。

## 0.2：自研运行闭环

已实现自己的数据解释器、播放调度、DOM 图层/聊天/调查渲染、输入/弹层/设置/存档、声音宿主，以及独立作品的离线构建。Rain 数据可直接由自研 VM 执行，四种样例可在子目录与断网状态运行。

## 0.3：作者工具与 Windows 宿主

已加入可视化节点图、分支和台词属性、资源绑定、诊断、撤销、草稿恢复与同一执行链预览。Windows 宿主提供原生窗口、受限文件 I/O、本地作品与持久化，并通过独立工作流验收。详见 EDITOR、WINDOWS 和 VALIDATION 文档。

## 0.4—0.6：作者工作台与 AI 生产

0.4 已补齐变量 / 章节工作台与有序效果；0.5 提供统一 SDK / CLI、回执恢复、真实预览和构建；0.6 提供制作上下文、实际素材探测 / 导入、主题及内容审查。条件 / 证据表单、正式图层与时间线、收藏作者工具等能力的具体范围见对应版本验证记录。

## 后续作者需求

R3 计划、实现范围与验收矩阵见 [记录](R3_PLAN.md)。更深入的演员定位、演出扩展、资产包协作和大工程性能需以具体作品需求与测量结果另行确定，不据旧路线图重复实现已经验收的基础能力。

## 引擎宿主与稳定性

优先优化执行、调度、资源生命周期、演出与性能；桌面宿主也先以引擎独立样例验证。四个正式项目维持各自运行链。

## 四作迁移：仅用户主动提出后执行

迁移属于最后阶段。用户主动、明确提出后再制定和执行迁移方案，保留人物、玩法、数据和存档身份，并分别验证实际平台。本文不授权提前接入任何原项目。原 Rain 二进制存档不会被自研 VM 直接读取，需要专门的迁移桥。

## 发行标准

继续完善跨版本存档策略、资源诊断、可复现构建和平台验收，再决定包发布。每阶段按实际证据记录，不把原生平台未执行或正式素材未审读记作完成。
