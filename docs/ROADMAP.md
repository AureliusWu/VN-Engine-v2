# 后续工作

## 0.1：已形成的雏形

独立剧情/调查核心、三作适配器、Rain 原生编译桥接、媒体生命周期、历史搜索与重读、存档边界、离线工具、最小样例与原码对照。

## 0.2：宿主协议

将段落开始、句尾停顿、事件图、音效与访问 ID 形成明确的宿主事件协议；补充能实际绘制资源的独立渲染示例，验证键盘、移动触控、后台与面板暂停。继续保留聊天、通讯卡、现场人物和调查文书的独立呈现。

## 0.3：作者工具

为新项目定义有版本的数据格式、资源清单与诊断输出；接入稳定台词 ID、变体配音、预览和离线资源验证。先补功能测试与可迁移的作者示例，再考虑可视化编辑器。

## 项目消费验证

单独挑选一个源项目的低风险共用模块做依赖接入，从音乐/搜索等边界明确的模块开始。完成旧档、完整备份、浏览器与真实平台回归后，再扩大范围。这里列出后续路径，不表示已经迁移四作。

## 独立发行能力

补 Electron/Tauri/原生 Ren’Py 的宿主模板与实际执行验收，再定义引擎版本兼容策略和包发布方式。不会因核心测试通过就标记为可完整替代四作原发行链。
