# v2.1.0 工程导入与 DSL 源稿验证

浏览器回归实际打开带坏台词的 JSON、在当前工程应用坏 JSON，并核对标题、草稿身份、资源绑定、预览、导出和撤销历史。调查章节的坏证据目录也在替换前被拒绝。有效但待修的断链或证据引用继续进入编辑器。

DSL 回归覆盖未编译源稿保存、重新打开并继续编辑、重新编译和应用、撤销和重做、运行 JSON 隔离，以及恢复文件中的已保存源稿和待保存文本。Windows 预设路径回归核对原生打开与保存。 [本轮计划](PLAN-v2.1.0.md)

本地检查计数和源文件摘要见证据索引。交付证据汇总为本地 `test-results/v2.1.0-delivery.json`。Windows CI 文件对话框使用预设路径。实体设备与内容验收另有流程。 [本地证据索引](v2.1.0-validation.json)
