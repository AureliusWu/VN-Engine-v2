# v1.4.6 Studio 导入、草稿与候选试玩验证

| 场景 | v1.4.5 复现 | v1.4.6 验证 |
| --- | --- | --- |
| 打开或应用分支列表误写为对象的 JSON | 构图报错后内部工程已替换。文件打开还清除了资源目录，应用时显示旧侧栏和禁用的撤销按钮。 | 拒绝发生在模型提交前。保留工程、绑定、已挂载预览和撤销历史。带缺失目标的有效列表可打开，补齐连线后可试玩。 |
| 修改 A 后立即接受替换为干净 B | A 的 350ms 回调在切换后将 B 写进草稿槽，重载恢复 B。 | 替换前同步保存 A 的最新改动，取消旧回调。B 上直接应用未修改的 JSON 不覆盖 A，重载可恢复 A。 |
| 仅格式化 JSON 后应用 | 工程未变化，界面仍报未保存，重载后恢复未应用文本。 | 立即显示已保存，面板保留格式，未增加撤销项。持久草稿去掉未应用文本，重开不会复活。 |
| DSL 候选被缺资源诊断拦截 | 编译成功且界面报告正在预览，实际仍为旧对白和旧 revision。 | 面板明确显示候选试玩未启动，保留编译结果和旧画面。重新绑定完整目录后可用原候选真实试玩。 |
